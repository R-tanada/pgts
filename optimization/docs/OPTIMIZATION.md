# 固定歯数での転位係数の最適化

## 転位範囲±2.0と±0.9の比較

```powershell
python code/optimize_profile_shift.py --compare-limits
# または
python code/compare_shift_limits.py
```

両ケースを同じ歯数、μ、かみあい率・干渉条件、初期値数、乱数シードで独立に最適化します。乱数の正規化座標は同じで、実際の初期値は各探索範囲に合わせて変換します。

`optimization_output/limits_comparison.html` に数値と全8図を左右に並べて保存します。対応する数値軸と断面の色尺度を共通にしています。目的関数断面・感度図の他の変数は各ケースの最適値に固定します。初期値・反復スライダーは各ケースのページで操作できます。

数値は `limits_comparison.csv`、設定と比較は `limits_comparison.json`、各ケースの詳細は `limit_2.0` と `limit_0.9` に保存します。既存の単一ケース出力は維持します。転位の論文値は±0.9の範囲に入らないため、狭い範囲の可行解として扱いません。

Table IIIの歯数とモジュールを固定し、順駆動効率を最大化します。論文の転位係数は、目的関数にも初期値にも使いません。比較用の定数としてのみ保持しています。

| 量 | 値 |
|---|---:|
| zs | 12 |
| zp1 | 39 |
| zr1 | 90 |
| zp2 | 32 |
| zr2 | 81 |
| N | 3 |
| ma=mb [mm] | 0.8 |
| mc [mm] | 0.8467 |

Type-I構成: S入力、R1固定、R2出力。固定歯数から求まる減速倍率は約96.241935です。減速比は転位で変わらないため、連続最適化の制約に入れず結果に表示します。等配条件も固定歯数について事前に確認します。

## 独立変数と中心距離

独立変数は `[xr1, xr2, center_mm]` の3つです。

1. 共通中心距離から各かみあいのかみあい圧力角を式(81)で計算。
2. 式(88)から `Ka=xs+xp1`、`Kb=xp1-xr1`、`Kc=xp2-xr2` を計算。
3. `xp1=xr1+Kb`、`xs=Ka-xp1`、`xp2=xr2+Kc` を求める。

これにより、中心距離の一致を等式制約として数値的に解かずに厳密に組み込めます。全5歯車の転位上下限は、従属変数も含めて判定します。中心距離の探索上限は転位和の上限から導き、論文の中心距離付近に範囲を絞りません。

## 目的関数

- 歯先径: 式(82)-(86)。特にP1の歯先径は式(83)の `min(ya-xs, xp1)` を使います。
- 接近・遠のきかみあい率: 式(79)、(80)。合計が一般にいうかみあい率です。
- 各対の基礎効率: 式(77)、(78)。全対で同じ歯面摩擦係数μを使用。
- 順駆動効率: I2<1なら式(64)、I2>1なら式(67)。SLSQPにはその負値を渡します。

**歯面摩擦係数μの具体値は本文から確認できませんでした。既定値0.1は仮定で、論文に合わせた推定値ではありません。** `friction_coefficient` を変えて再計算できます。本文にある一般モデルのμ′=0.01とは別の係数です。

## 制約

`constraint_margins()` が、名前と余裕量の辞書を返します。すべて非負なら合格です。

- 各転位係数: 既定 `-2 <= x <= 2`（式91）。
- 共通中心距離: 従属変数の計算に組込み（式92）。
- 3対のかみあい率: 既定1～2。
- 歯先円が基礎円の外側にあり、接近・遠のき区間が非負。作用線上のインボリュート干渉を除外。
- P1-R1とP2-R2のトロコイド干渉: 歯先円の交点と歯位相による角度式を使用。無転位用の「歯数差10以上」を転位後に流用しません。
- 各層で隣接遊星の歯先円間のすきまを確保。
- トリミング: KHKの角度式。既定では制約に含めます。`include_trimming_constraint=false` にすれば半径方向の組付け条件を外せます。工具との干渉は対象外です。
- 基礎効率と順駆動効率が0～1の範囲。

切下げ、歯強度・許容トルク、工具の創成歯形・フィレット、実歯形の全面的な衝突判定は含みません。論文の全製造条件を再現した最終設計ではありません。

## 最適化法と採用条件

[SciPyのSLSQP](https://docs.scipy.org/doc/scipy/reference/optimize.minimize-slsqp.html)を使います。SQP系の一般的な制約付き非線形最適化法です。変数を0～1に正規化し、有限差分で勾配を計算します。

固定シードの12初期点で探索し、ソルバーの成功判定に加えて、終了点のすべての制約を再評価します。収束した可行解から順駆動効率が最大のものを採用します。失敗した試行もJSONに残します。すべて失敗した場合は非ゼロ終了し、成功した結果として報告しません。複数初期値は安定性確認であり、大域最適性の保証ではありません。

## 論文値との比較で注意する点

Table IIIの転位係数は小数3桁、mcは小数4桁に丸められています。これらから3対の中心距離を独立に復元すると、a/bは約21.267911 mm、cは約21.268662 mmです。比較用のモデル評価はaから復元した共通中心距離を使い、従属転位を再計算します。丸められた5つの転位を、中心距離が完全に一致する値として扱いません。

同じ式で論文値を評価すると、かみあい率a/cはほぼ表と一致しますが、bは約1.316で表の1.420と一致しません。コードでは式(83)を別の歯先径に置き換えて表へ合わせていません。この不一致と摩擦係数の仮定があるため、最適転位の差をソルバーの差だけで説明することはできません。

提供PDFにはTable Vがなく、順効率89.0%・逆効率85.3%はTable IVの実測値です。式による予測値と分けて比較し、差はパーセントポイントで記録します。

目的関数は、固定歯数でI2<1なので式(64)だけです。逆効率は結果の評価にだけ使います。印刷された式(75)はそのまま残す一方、式(74)のトルク釣合いを独立に解いた逆効率も保存します。

```text
印刷式(75):
eta_reverse = (1+I1)*(eta_b*eta_c-I2) / (eta_c*(eta_a*eta_b+I1)*(1-I2))

式(74)のトルク釣合いから再導出:
eta_reverse = (1+I1)*eta_a*(eta_b*eta_c-I2) / (eta_c*(eta_a*eta_b+I1)*(1-I2))
```

両者にはeta_aの因子の差があります。2x2の力釣合い方程式を直接解く別経路のテストでも再導出式を確認しました。既定μ=0.1では順91.985867%、印刷式の逆93.216316%、再導出した逆91.521945%です。論文に合わせて式や摩擦係数を変更していません。

## グラフで学ぶ

通常の実行で8種類のPNG/SVGと `learning_graphs.html` を生成します。HTMLをブラウザで開くと、初期値を選んで反復スライダーを動かせます。外部通信はありません。最適化をやり直さずグラフだけ再生成する場合は `learning_plots.py` を使います。

| 図 | 学習する内容 |
|---|---|
| 1. 収束と可行性 | 効率が高くても制約違反の点は解として採用できない。失敗試行も表示 |
| 2. 独立・従属変数 | 3変数の最適化から5つの転位係数が決まる関係 |
| 3. 目的関数の断面 | 灰色の不可行領域、制約境界、最適解の位置 |
| 4. 局所感度 | 内点の山と、傾きがゼロでなくても最適となる境界解 |
| 5. 効率比較 | 実測値とモデル予測、逆効率の印刷式と再導出式の違い |
| 6. 活性制約 | xr1の上限が解を制限していること、他の制約の余裕 |
| 7. 摩擦係数の影響 | 転位を固定してμだけ変えた感度。再最適化やフィットではない |
| 8. かみあい率と損失 | 表と式の不一致、各かみあいの基礎損失と全体損失の違い |

収束履歴の反復0は初期点で、以降はSLSQPのコールバック点です。目的関数の断面では他の変数を最適値に固定します。断面図・感度図だけで大域最適性を保証できるわけではありません。
