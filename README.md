# 歯車設計ツール

PySide6による、遊星歯車と単純な外歯車対の設計・プレビューツールです。
`main.py` から起動し、「遊星歯車」「単純歯車対」のタブで切り替えます。
入力値はタブごとに保持し、タイトルバー・数値入力カード・ライト／ダークテーマを共用します。

## 起動

Python 3.10以上で依存パッケージをインストールして実行します。

```powershell
python -m pip install -r requirements.txt
python main.py
```

既存の仮想環境を使う場合も、NumPy追加のため依存関係を更新してください。

```powershell
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe main.py
```

## 単純歯車対の操作

- モジュール・圧力角・各歯車の歯数／転位係数を直接入力、上下矢印で変更できます。
- 基準円・基礎円・歯底円・歯先円・作用線などの表示と強調、円弧／トロコイド歯元の切替に対応します。
- 左ドラッグで移動、ホイールで拡大縮小。「全体を表示」で表示範囲を戻せます。寸法変更時も全体表示します。
- 再生／一時停止と角度リセットに対応。タブ移動時は一時停止し、角度・入力を保持します。
- 現在の角度と補助線をPNG（透明背景）／SVGに保存できます。
- 元コードのバックラッシ入力は実際には**各歯車の歯厚減少量**だったため、その名前に変更しました。転位なしの歯車対全体の隙間は入力値の2倍です。
- 中心距離は基準円半径の和で固定です。転位時の中心距離補正・干渉判定は未実装で、画面に参考表示の注意を出し接触点を隠します。円弧モードの歯底半径も転位によらない元の簡略モデルを継承します。
- `simple gear` の歯形計算を `simple_gear/geometry.py` に移し、画面・描画・計算を分離しました。旧フォルダは参照用に残しています。統合版はルートの `main.py` を使用してください。

## 遊星歯車の操作

- 画面はパラメータ・制約条件・プレビューの3列です。制約名を数式より大きく表示し、✓ 適合・× 不適合・△ 注意・? 判定不可を色と記号で区別します。各制約をクリックすると数式と説明を開閉でき、入力変更・テーマ切替でも開閉状態を保持します。未操作の不適合項目は詳細を表示します。小さいウィンドウでは各列をスクロールできます。
- ライトテーマはミスト（淡いグレーと青）。外枠を明示し、タブは左から「単純歯車対」「遊星歯車」です。起動時は単純歯車対を表示します。太陽は青、遊星は青緑、リングは青灰色で描画し、歯車の色凡例は表示しません。
- プレビュー上部にリング固定・太陽入力・キャリア出力の減速比 `i = n_s/n_c = 1 + z_r/z_s` を表示します。例えば太陽20・リング60なら4:1。歯数・配置・運転干渉条件が不適合の場合は理論参考値と明記します。

- ライトモードが初期状態。タイトルバーの月／太陽アイコンで切り替えます。
- 独自タイトルバーをドラッグして移動、ダブルクリックまたは□で最大化・復元します。
- 四辺・四隅でウィンドウをリサイズできます。OS標準のリサイズ処理を使用します。
- パラメータは直接入力、または上下矢印で変更します。直接入力はEnterまたはフォーカス移動で確定します。
- 「遊星歯数を合わせる」はリングと太陽を保持し、遊星歯数を `(リング歯数 − 太陽歯数) / 2` に設定します。転位OFF時のみ使用できます。整数にならない場合、入力範囲外の場合は変更せず理由を表示します。拘束かみ合い条件は別途判定します。
- そのボタンの下の「転位を使用する」をONにすると、太陽・遊星・リングの転位係数を独立入力できます。全遊星に同じ係数を使用します。入力範囲は −1〜+1、刻み0.01、直接入力は小数6桁まで。OFF時は入力を保持して有効係数をすべて0に戻し、表示式・判定・歯形も転位なしに戻します。
- 制約条件は「遊星歯車の成立条件」「内歯車の制約（遊星–リング）」「外歯車の制約」で分類し、各カードを開くと現在のモードの式・判定値が見られます。転位ONでは歯数関係だけでなく、2組のかみ合い圧力角から求めた中心距離の一致で判定します。拘束かみ合い条件の式はON/OFF共通です。
- 歯数・配置・運転中の内歯干渉条件が不適合／判定不可でもリングと太陽は参考形状として表示し、遊星のみ隠します。上部に確認項目、左側に数値・理由を表示します。トリミング・切下げは加工／組立上の注意として表示を維持します。個別の歯形自体を生成できない場合はその歯形を隠し、リングは外周・ピッチ円を残します。
- 設計基準円はmm単位の直径を指定します。茶色の破線で示し、歯数・モジュールを変えても指定直径を保持します。リング外径との直径差・超過量を表示します。超過は組立制約とは独立した寸法比較です。
- リング外周の厚さは歯元円から外周までの半径方向の距離です。外径は `m × (リング歯数 + 2.5 + 2x_r) + 2 × 外周の厚さ`（転位OFFでは x_r=0）。初期厚さ3.5 mmは設計強度に基づく推奨値ではありません。
- 表示倍率は基準円と歯車が収まるよう自動調整します。円の比較は同一縮尺で行います。詳細な歯形は高解像度画像として再利用し、リサイズ中の頂点再計算・再描画を避けています。
- 初期値の太陽20・遊星20・リング60・遊星3個は均等配置とインボリュート干渉回避条件に不適合です。旧版の「遊星4個にすれば表示できる」は配置条件だけの判定でした。圧力角20°で太陽18・遊星21・リング60・遊星3個は今回の検査項目に適合します。

## 計算と適用範囲

中心距離条件、拘束かみ合い条件、外径干渉条件を判定します。中心距離条件は転位OFFでは従来の歯数関係と等価、ONではかみ合い中心距離の一致です。外径干渉は共通中心距離と転位後の遊星歯先径から判定します。中心距離が未成立の場合、共通軸位置を定められないため外径干渉は判定不可になります（遊星1個なら対象なし）。
入力欄の上下限はアプリの対応範囲であり、設計の成立条件ではありません。範囲内でも干渉することがあります。
遊星–リングのインボリュート干渉・トロコイド干渉・トリミング干渉、太陽／遊星の標準ラック創成時の切下げ限界を解析式で検査します。
式・適用範囲・描画の原因調査は [設計計算メモ](DESIGN_NOTES.md) を参照してください。
外歯・内歯ともインボリュート歯面を使用し、基準円歯厚は転位OFFでは半ピッチ、ONでは外歯が `m(π/2+2x tan α)`、内歯が `m(π/2−2x tan α)` です。
太陽・遊星・リングのかみ合い位相を合わせます。
歯先・歯元は円弧接続し、基礎円より内側は径方向の簡略接続です。

歯先短縮なし・標準歯たけ・理論バックラッシ0のモデルです。工具による歯元創成、切下げ量と切下げ後の形状、工具と内歯の歯切り干渉、太陽–遊星の詳細干渉、かみあい率、強度、実バックラッシは未評価です。
「検査項目に適合」は製作可能性を保証しません。歯先や歯元が反転する入力ではその歯形の表示を停止します。

参考：[KHK 内歯車技術資料](https://khkgears.net/pdf/2025/internal-gears.pdf)

## ファイル

- `main.py`：起動
- `gui.py`：共通タイトルバー・テーマ・タブ切替
- `planetary_page.py`：遊星歯車の日本語UI・数式表示・プレビュー
- `ui_common.py`：共通配色・数値入力カード
- `simple_gear/geometry.py`：単純歯車の歯形計算
- `simple_gear/view.py`：歯車対描画・回転・画像出力
- `simple_gear/page.py`：単純歯車対の入力・表示操作
- `ui_widgets.py`：数式の軸合わせ、ベクター描画アイコン、リサイズ操作
- `gear.py`：歯形・配置・基本制約
- `interference.py`：内歯干渉・切下げの解析式検査
- `DESIGN_NOTES.md`：式、用語、適用範囲と描画原因調査
- `test_gear.py`：輪郭順序、基準円歯厚、位相、制約の回帰テスト
- `test_gui.py`：入力・テーマ・プレビュー状態のオフスクリーンテスト
- `test_interference.py`：公表された歯数境界、適用範囲、中心距離式の照合
- `test_tabs.py`：タブの状態保持、回転位相、テーマ、エラー回復、PNG／SVG出力
- `test_shift.py`：転位ON/OFF、KHK計算例、歯数関係を満たさない中心距離一致、転位歯厚・歯先径、干渉・切下げ、UI状態保持

```powershell
.venv\Scripts\python.exe -m unittest -v
```

画面テストは `artifacts/` に確認画像を書き出します。
オフスクリーン検証には、実際のWindowsタイトルバーのドラッグ操作は含まれません。
リサイズ試験は300歯のリングを使い、24段階のサイズ変更と再描画を計測します。
辺・角からOSのリサイズAPIに正しい方向を渡すこともテストしますが、実際のマウス操作の感触は対象外です。
